## 1. 概要

- ブラウザで動く、整数と小数の四則演算ができる電卓
- 入力できる数は8桁まで。`-` と `.` は桁数に数えない（例：`-123.4567` は7桁）
- 計算は左から順に行う。`×` `÷` を先に計算しない（例：`3 + 2 × 4 = 20`）
- 小数の計算で誤差が出ることは許容する
- 使う技術：TypeScript、Vite、Vitest
- 動作環境：Google Chrome・Microsoft Edge の最新版

## 2. 画面

### 2.1 ボタン

| ボタン | 必須 | 役割 |
| --- | --- | --- |
| `0`〜`9` | 必須 | 数字を入力する |
| `.` | 必須 | 小数点を入力する |
| `+` `-` `×` `÷` | 必須 | 演算子を入力する。`-` は負の数の符号にもなる |
| `=` | 必須 | 計算する |
| `C` | 必須 | すべて消して最初の状態に戻す |
| `⌫`（1文字消去） | 任意 | 無くても合格（QA No.4）。今回は作る。動きは 3.8 |
| `AC` | 任意 | 無くても合格（QA No.4）。`C` との違いが決まっていないため、作るかどうかは未定 |

### 2.2 表示エリアと履歴エリア

| エリア | 必須 | 表示するもの |
| --- | --- | --- |
| 表示エリア | 必須 | 入力中の数、または計算結果。最初は `0` |
| 履歴エリア | **必須**（QA No.7） | 表示エリアの左上に、入力済みの計算式を小さい文字で表示する |

履歴エリアの表示例：

| 操作 | 表示エリア | 履歴エリア |
| --- | --- | --- |
| `3` `.` `5` | `3.5` | （空） |
| `+` | `3.5` | `3.5 +` |
| `-`（上書き） | `3.5` | `3.5 -` |
| `2` | `2` | `3.5 -` |
| `=` | `1.5` | `3.5 - 2 =` |
| `÷` | `1.5` | `1.5 ÷` |
| `0` `=` | `エラー` | `1.5 ÷ 0 =` |

## 3. 入力

### 3.1 数字

- 押した順に入力する
- 8桁を超える入力は無視する
- `0` のあとに `0` を押しても `0` のまま

### 3.2 小数点（QA No.2）

- 数がまだ無いときに `.` を押すと、`0.` にする
- 1つの数の中で `.` は1つだけ。2回目以降は無視する

### 3.3 マイナス（QA No.8）

- 数がまだ無いとき（最初・`C` の後）に `-` を押すと、負の数の入力を始める
- 演算子を押した直後に `-` を押すと、演算子の上書きになる（負の数の入力にはならない）
- そのため、`3 × -2` のように2つ目の数を負の数にする入力はできない（講師確認済み）

### 3.4 演算子

- 数がまだ無いときは無視する（`-` を除く。3.3 のとおり）
- 演算子を続けて押したら、後から押したもので上書きする
- 1つ目の数・演算子・2つ目の数がそろっているときに演算子を押すと、その場で計算し、結果を次の計算の1つ目の数にする

### 3.5 イコール

- 1つ目の数・演算子・2つ目の数がそろっているときだけ計算する
- そろっていないときは何もしない（表示もそのまま）
  - 例：`3 =`、`3 + =`

### 3.6 入力中の表示（QA No.5）

- 入力中は、押したとおりに表示する（例：`3` `.` と押すと `3.`）

### 3.7 クリア

- `C` を押すと、入力中の数・演算子・計算途中の値・履歴をすべて消し、表示を `0` にする

### 3.8 1文字消去（⌫）

講師の回答で任意機能とされたため、動きは自分で決めた。

- 入力中の数の、最後の1文字を消す（例：`123` → `12`、`3.` → `3`）
- 消して空になったときは、1つ目の数なら表示を `0` に、2つ目の数なら1つ目の数の表示に戻す
- 入力中でないとき（演算子を押した直後・計算結果の表示中・エラーの表示中）は無視する

## 4. 計算結果の表示

### 4.1 小数の桁（QA No.9）

- 計算結果が8桁を超える小数のときは、8桁を超えた分を切り捨てる
  - 例：`1 ÷ 3` → `0.3333333`
- `0.1 + 0.2` の表示は確認中（QA No.11）

### 4.2 指数表記（QA No.3）

- 指数表記の桁数は、小数点と `e+` を除いて8桁で数える
  - 例：`1.2345678e+2`
- 指数表記にする条件（整数部が8桁を超えるときだけか）は確認中（QA No.12）
- `e+` の後ろの数字を桁数に含めるかは確認中（QA No.13）

---

## 5. エラー（QA No.1）

- 0で割ったときは、表示エリアに `エラー` と表示する
- エラーの詳しい内容は、ブラウザのコンソールに出す
- エラーになったら、入力中の数・演算子・計算途中の値を消す
- エラーの後は、`C` で最初の状態に戻る。数字か `.` を押したときは、新しい計算を始める（詳細設計 4章）
